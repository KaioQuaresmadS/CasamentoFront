# Fotos do site

Coloque as fotos nesta pasta usando exatamente estes nomes:

- `capa-principal.jpg`: foto grande do topo da pagina inicial.
- `confirmar_presenca.jpeg`: foto central da secao de confirmacao de presenca.
- `fundo-confirmar-presenca.jpg`: background separado da secao de confirmacao de presenca.

Para trocar uma foto, substitua o arquivo mantendo o mesmo nome.
